# DSA in C — From Scratch

A beginner-friendly guide to **Data Structures and Algorithms in C**, built to be studied and practiced together with Claude.

Buckle up. 🚀

---

## Why C?

- **Simple.** The language is small, so you spend your time learning DSA, not language features.
- **Full memory control.** You decide how memory is allocated, used, and freed, which is exactly what makes data structures click.
- **Beginner-friendly.** Nothing is hidden from you. You see what the machine is really doing.

---

## What you should already know

You only need the basics:

- Variables and data types
- `if` / `else`
- A few simple loops (`for`, `while`)
- Basic syntax (how to write, compile, and run a C program)

That's it. You don't need to be an expert.

---

## What we'll learn from scratch

These four topics are the foundation of everything in DSA, so we start here and build up slowly:

1. **Pointers**: how memory addresses work
2. **Recursion**: solving problems by breaking them into smaller ones
3. **Arrays**: contiguous memory and indexing
4. **Structures**: grouping data into your own types

---

## Suggested roadmap

| Stage | Topics |
|-------|--------|
| 1. Foundations | Pointers, recursion, arrays, structures |
| 2. Linear structures | Linked lists, stacks, queues |
| 3. Searching & sorting | Linear/binary search, bubble, selection, insertion, merge, quick sort |
| 4. Non-linear structures | Trees, BST, heaps, graphs |
| 5. Practice | Problems and mini-projects |

## How to use this repo

1. Read the notes for a topic.
2. Compile and run the examples yourself:
   ```bash
   gcc example.c -o example
   ./example
   ```
3. Modify the code, break it, and fix it. That's where the learning happens.
4. Ask Claude whenever something is unclear.
