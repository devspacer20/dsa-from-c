# Pointers

> A crucial concept in programming.

A **pointer** is a variable that stores the address of another variable.

---

## 1. Pointer Notation

```c
int i = 3;
```

This declaration tells the C compiler to:

1. Reserve space in memory to hold the integer value.
2. Associate the name `i` with this memory location.
3. Store the value `3` at this location.

---

## 2. Code Snippet

> This is not the full program, only the relevant part.
> Full code: `dsa-from-c/Ch-001.basics/2.src`

```c
int i = 3;
printf("address of i is %u\n", &i);
printf("value of i is %d\n", i);
```

### Output

```
address of i is 65524
value of i is 3
```

---

## 3. Explanation

- `i` holds the value `3`.
- `&i` gives the **address** of `i` in memory.
- A pointer is a variable that holds such an address.

---

## 4. Summary

In simple terms, a pointer takes the address of a variable.
